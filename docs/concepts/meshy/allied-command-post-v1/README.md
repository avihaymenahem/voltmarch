# Allied Command Post v1

2x2 / 10.5 m Allied command building. The building is an aerial: a low bunker body supports one tall raked communications mast and a static horizontal yagi. Nothing rotates, and there is no dish.

`geometry-sheet.png` and its four cardinal crops are the locked reconstruction source.

Material target: white ceramic bunker, graphite recesses, chrome mast, cobalt glazing, cyan communications accents, amber obstruction beacon.
