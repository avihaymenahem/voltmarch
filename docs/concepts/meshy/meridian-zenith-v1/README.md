# Meridian Zenith Emitter V1

Status: integrated · content key: `meridian_zenith` · created 2026-08-30

The four-view sheet defines a four-fan hexagonal hover chassis and one short jade crystal emitter,
with no conventional barrel. Meshy geometry task `01a05060-db72-72e2-ab7d-fdcb707747df`
consumed 20 credits and returned 1,977,858 raw triangles. The accepted 24,780-triangle source uses
a bounded `Hull`/`Emitter` split. PBR task `01a05063-3bdb-7675-9ce7-fbb2b3b3bc17` consumed 10 credits.

The bounded ring at `[-0.08, 0.05, 0]` prevents rear mirror vanes or fan parts from rotating with
the emitter. Runtime ships KTX2 LOD0 and a 1,680-triangle shadow proxy.
