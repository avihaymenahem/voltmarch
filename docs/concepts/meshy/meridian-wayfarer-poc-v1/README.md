# Meridian Wayfarer POC concept

ImageGen-authored orthographic T-pose sheet for the first rigged Meridian
infantry proof. `turnaround.png` is the preserved source sheet; `views/` contains
the deterministic front/right/back/left crops supplied to Meshy Multi-Image to
3D. The runtime result is owned by
`packages/assets/game/units/meridian/infantry-poc/`.

Locked cues: ceremonial hexagonal torso, conical helmet, attached canted mirror
vane, warm bone ceramic shell, cool Meridian plate fields, restrained gold trim,
and separated joints suitable for a humanoid rig.
