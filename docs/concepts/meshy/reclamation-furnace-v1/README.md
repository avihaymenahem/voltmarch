# Reclamation Scrap Furnace v1 — geometry contract

- Compact 2x2 power plant with exactly one thick faceted tapping stack on the physical right-rear corner.
- One physical-left cooler bank, one front furnace throat/spout and one low offset arc coil.
- No mirrored stack, tower, crane, antenna, cable, railing or floating part.
- Target: 18k-28k triangles at LOD0 after local retopology.
- Procedural Furnace remains the load-failure fallback until every runtime gate passes.
