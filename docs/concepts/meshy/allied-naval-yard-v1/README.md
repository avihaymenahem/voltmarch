# Allied Naval Yard v1

3x3 / 7.5 m Allied waterline factory. A broad open ship slip runs through the centre toward the front sea exit. Two fabrication wings flank it and a single solid rear gantry spans above; the exit may never be blocked by decorative geometry.

`geometry-sheet.png` and its four cardinal crops are the locked reconstruction source.

Material target: white ceramic fabrication wings, graphite dock deck, chrome gantry, cobalt workshop glazing, cyan navigation strips, amber dock lights.
