# Reclamation Rookery v1 — geometry contract

- Compact 2x2 personnel structure with one recessed front doorway and short ramp.
- One offset squat ventilation tower and two fused roof cargo pods.
- No mirrored doorway, giant tower, railing, cable, ladder, antenna or floating part.
- Target: 15k–25k triangles at LOD0 after local retopology.
- The procedural Rookery remains the socket authority and load-failure fallback.
