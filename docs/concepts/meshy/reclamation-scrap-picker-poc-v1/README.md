# Reclamation Scrap Picker POC concept

ImageGen-authored orthographic T-pose sheet for the first rigged Reclamation
infantry proof. `turnaround.png` is the preserved source sheet; `views/` contains
the deterministic front/right/back/left crops supplied to Meshy Multi-Image to
3D. The runtime result is owned by
`packages/assets/game/units/reclamation/infantry-poc/`.

Locked cues: forward wedge torso, squat helmet and canted visor, one asymmetric
pauldron, attached offset arc coil, graphite salvage frame, violet armor blocks,
restrained hazard amber, and separated joints suitable for a humanoid rig.
