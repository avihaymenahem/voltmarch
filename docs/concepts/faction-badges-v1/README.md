## Shared badge contract

- Front-facing, centered, compact medallion/shield composition.
- No lettering, numbers, flags, backing card, scenery or watermark.
- Genuine alpha transparency and a consistent clear margin.
- One dominant glyph with broad masses that survive UI downscaling.
- Faction identity comes from silhouette and construction language as well as colour.
- The four outer silhouettes deliberately differ: tall/aerospace, broad/grounded,
  suspended/ceremonial and open/asymmetric.
