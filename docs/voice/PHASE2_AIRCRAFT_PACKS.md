# VOLTMARCH Phase 2 Aircraft Voice Packs

Status: scripts locked; casting in progress
Owner: game/audio
Last audited: 2026-08-26

Aircraft speak only for selection and explicit orders. No autonomous damage,
veterancy, arrival or idle chatter is commissioned. Each pack contains 21
takes: four select, four move, four attack, three attack-move, two stop, two
guard and two patrol acknowledgements.

## `AL-AIR` — Allied Petrel pilot

| Category | Approved transcripts |
| --- | --- |
| `select` | Petrel flight online. / Pilot ready. / Flight systems green. / Air tasking standing by. |
| `move` | Vector confirmed. / Moving to waypoint. / Flight path accepted. / Petrel repositioning. |
| `attack` | Weapons free. / Rolling onto target. / Strike solution confirmed. / Committing ordnance. |
| `attackMove` | Sweeping the route. / Advancing with weapons ready. / Flight corridor contested. |
| `stop` | Holding the orbit. / Cancelling the run. |
| `guard` | Covering the formation. / Protective orbit established. |
| `patrol` | Beginning patrol circuit. / Running the air screen. |

Casting: Allied tactical aviator; fastest faction cadence, crisp and restrained,
technically fluent without swagger or pilot clichés.
