# Campaign portraits

`portraits/rakhalt.webp` and `portraits/vosk.webp` are original AI-assisted
character artwork generated for VOLTMARCH with OpenAI's built-in image
generation tool on 2026-08-21. They are campaign/interface assets, not models
or textures used by the procedural game world.

The two portraits were authored as one visual set: fictional identities,
matching command-compartment lighting, matching Soviet March uniform language,
and square framing that survives both the briefing card and the smaller in-match
communications crop. The source generations remain in the local Codex generated
image store; the shipped WebP files are 640 x 640 delivery derivatives.
