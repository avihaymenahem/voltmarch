# Campaign portraits

`portraits/rakhalt.webp`, `portraits/vosk.webp` and `portraits/wend.webp` are
original AI-assisted character artwork generated for VOLTMARCH with OpenAI's
built-in image generation tool on 2026-08-21. They are campaign/interface
assets, not models or textures used by the procedural game world.

The portraits were authored as one visual set: fictional identities, matching
command-compartment lighting and square framing that survives both the briefing
card and the smaller in-match communications crop. Rakhalt and Vosk carry the
Soviet March's charcoal-and-red uniform language; Wend carries a separate
Allied navy-and-cyan material language without changing the rendering style.
The source generations remain in the local Codex generated image store; the
shipped WebP files are 640 x 640 delivery derivatives.
